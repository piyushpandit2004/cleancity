# CleanCity – Smart Waste Management System

A web application for smart waste management using Java Spring Boot, Spring Security, JWT, MySQL, and a web frontend.

## Technologies Used
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- HTML, CSS, JavaScript

## Features
- User Registration and Login
- JWT-based Authentication
- Waste Complaint Management
- Admin , Worker and Citizen Roles
- Complaint Status Tracking
